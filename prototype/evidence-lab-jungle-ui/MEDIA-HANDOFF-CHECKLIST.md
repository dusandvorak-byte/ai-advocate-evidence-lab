## Preflight: examine the original ZIP in an isolated local working directory
1. Preserve the source ZIP byte-for-byte and calculate its SHA-256 before extraction; retain chain-of-custody notes including sender, retrieval date, and transfer channel.
2. Inspect member names and sizes without extraction. Reject absolute paths, `..` traversal, symlinks, unexpected types, nested ZIPs, more or fewer than five image files, or excessive decompressed sizes; do not auto-open executable contents.
3. Compare every JPEG hash against a **separately trusted** SHA256SUMS source. An internal matching manifest only proves that the archive's files match that manifest; it does not prove Dušan's original source or authorization.
4. Decode images read-only to verify JPEG format, dimensions and human-visible content. Expected dimensions from Sofie's inventory:
   - `Konopí.jpeg` — 720×450.
   - `Policie.jpeg` — 720×810.
   - `Srdce.jpeg` — 310×193.

   - `war is over.jpeg` — 720×511.
5. Check authorship, usage license, release scope, faces/personal data, visible text and metadata/EXIF. **Do not silently strip metadata from the required immutable originals**; create a separate approved display derivative only if permitted, preserving source bytes in restricted storage. Do not auto-crop the poster.
6. Obtain explicit editorial approval covering **each** image, site, caption and CZ/EN alt-text. Dušan's approval to transfer files is not automatically the same as approving public display or a PR merge.
